## How I'm Learning

I am following a day-by-day approach.

For each topic, I try to:

1. Understand the concept.
2. Write the code myself.
3. Test it.
4. Fix errors and understand why they happened.
5. Combine the concept with previous topics.
6. Keep the working code in this repository.

The repository is meant to show the actual progression, including the simple programs that came before the bigger projects.
